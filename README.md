# 🔍 CyberTrace — Digital Forensics Training

## About the Project

CyberTrace is an interactive digital forensics training application built using Python and Streamlit. It helps users learn about digital investigations through simulated cybercrime cases and digital evidence analysis.

Users can examine evidence, answer questions, analyse investigation records, and learn how digital forensic investigators identify and understand cybercrime.

## Features

- Interactive digital forensics investigation cases
- Simulated digital evidence and investigation records
- Multiple-choice questions with explanations
- Three difficulty levels: Beginner, Intermediate, and Advanced
- Investigation stages covering Overview, Evidence, Analysis, and Findings
- Score and progress tracking
- A dark-themed, interactive user interface

## Technologies Used

- Python
- Streamlit

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Install the required package:

   pip install -r requirements.txt

5. Run the application:

   streamlit run app.py

## Project Files

- **app.py** — Contains the main application code.
- **requirements.txt** — Lists the Python packages required to run the application.
- **README.md** — Provides project information and instructions.

## Project Purpose

The purpose of CyberTrace is to make digital forensics education more interactive and accessible through simulated cybercrime investigations.

**Note:** The investigation scenarios are simulated for educational purposes.
